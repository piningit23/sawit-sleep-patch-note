One line of patch notes announcing that human sleep is fixed: sleep
used to end after eight hours whether or not the human was rested —
now it saves progress instead of just pausing the game. The program
writes the line to `/output/entry.txt` for the make.fun judge to
compare against other entries.

## Run

```sh
python3 main.py
```

## Entry

> Fixed a bug where sleep ended after eight hours regardless of whether the human was rested; sleep now saves progress instead of just pausing the game.
